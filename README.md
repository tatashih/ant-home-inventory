# 螞蟻家庫存｜三人同步、獨立分區

[開啟庫存](https://tatashih.github.io/ant-home-inventory/)

- 塔塔小倉庫：螞蟻窩、狗窩。
- 朵朵小倉庫：螞蟻窩、貓居。

各區的商品清單、系列、名稱、補貨門檻、現貨、待到貨、備註與刪除均獨立管理。新增或修改其中一區不會更動其他區域。狗窩與貓居保留原有的零庫存品項作為起點，可自行增減。

## 待補貨與原有庫存

待補貨清單、首頁提醒、徽章及複製清單只統計兩個倉庫的「螞蟻窩」。狗窩、貓居不列入待補貨。

依使用者修正，原有庫存與待到貨全部保留在各倉庫的螞蟻窩；狗窩與貓居從 0 開始。未盤點品項維持待盤點，不當成 0。

## 使用與同步

查看及編輯均免密碼。選擇螞蟻、塔塔或朵朵後按「開始編輯」；任何持有連結者都能修改。選擇人員僅用於更新紀錄署名。

三人使用同一份 Google 試算表。開啟中的畫面每 30 秒更新，返回頁面或按重新整理也會同步；庫存修改有舊數量檢查，避免覆蓋其他人的更新。

## 原始碼與部署

- `index.html`：GitHub Pages 入口，導向 Google Apps Script。
- `apps-script/Index.html`：網站介面。
- `apps-script/Code.gs`：資料庫讀寫、分區遷移、異動紀錄及衝突檢查。
- `部署說明.txt`：最初版本說明，現行行為依本 README。

程式變更需在 Apps Script「管理部署作業」選取新版本並部署；只更新 GitHub 不會更新 Apps Script 已部署版本。重新開啟網站入口可載入新版。

資料庫「庫存」的 L 欄 productId 為歷史識別資料，M 欄 location 為存放區；既有 productId 相同的跨區資料也不再連動。系列分頁 F 欄 location 用於分區管理。歷史紀錄保留當時的實際操作，舊名稱在網站顯示為「螞蟻窩」。

遷移會先備份，保留原數量。歷次備份為「庫存_分區前備份_20261111」、「庫存_歸屬修正前備份_20261111」、「庫存_獨立分區前備份_20261111」。不要刪除指令碼屬性 STOCK_LOCATIONS_V1、STOCK_INDEPENDENT_V1 遷移標記。
